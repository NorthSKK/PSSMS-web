# เริ่มต้นใช้งาน PSSMS — สำหรับโรงเรียน

คู่มือนี้สำหรับ **ธุรการหรือครูที่ดูแลระบบของโรงเรียน** ทำครั้งเดียวตอนเริ่มใช้
ไม่ต้องมีความรู้เรื่องคอมพิวเตอร์เป็นพิเศษ ใช้เวลาประมาณ 1–2 ชั่วโมง
ถ้าเตรียมไฟล์รายชื่อไว้แล้ว

**สิ่งที่ต้องเตรียม**

- ลิงก์เข้าเว็บของโรงเรียน กับรหัสผู้ดูแลระบบ (ผู้ติดตั้งส่งให้)
- ไฟล์รายชื่อ **ครู** และ **นักเรียน** (Excel หรืออะไรก็ได้ที่พิมพ์เองใหม่ได้)
- **ตารางสอน** ของภาคเรียนที่จะใช้
- ไฟล์โลโก้โรงเรียน (ถ้ามี)

---

## ทำตามการ์ดบนหน้าแรก

เข้าระบบครั้งแรกจะเจอการ์ด **"ตั้งค่าเริ่มต้นของโรงเรียน"** อยู่บนสุดของหน้าแรก
บอกว่าเหลืออะไรบ้าง แต่ละข้อมีปุ่ม **"ไปตั้งค่า"** พาไปหน้าที่ต้องทำ

- ทำครบแล้ว **การ์ดจะหายไปเอง** ไม่ต้องกดปิด
- **ไม่ได้บังคับให้ทำตามลำดับ** กดดูส่วนอื่นก่อนได้ตลอด
- แต่ถ้าทำตามลำดับข้างล่างจะราบรื่นที่สุด เพราะบางอย่างต้องมีของอย่างอื่นก่อน

---

## ขั้นที่ 1 — ชื่อและโลโก้โรงเรียน

เมนู **ตั้งค่าระบบ** → กรอกชื่อโรงเรียน → บันทึก

ชื่อนี้จะขึ้นบนหัวเว็บ **และบนเอกสาร ปพ.5 ที่พิมพ์ออกมา** ใส่ชื่อเต็มอย่างเป็นทางการ

## ขั้นที่ 2 — ภาคเรียนและวันเปิด-ปิดเทอม

หน้าเดียวกัน เลือก **ภาคเรียนและปีการศึกษาที่ใช้งาน** แล้วกรอก **วันเปิด-ปิดภาคเรียน**

> **สำคัญที่สุดในคู่มือนี้** ข้อมูลทุกอย่างที่นำเข้าหลังจากนี้จะเข้าไปอยู่ใน
> ภาคเรียนและปีที่เลือกไว้ตรงนี้ · เลือกผิด = ข้อมูลทั้งโรงเรียนไปอยู่ผิดปี

วันเปิด-ปิดเทอมไม่ใช่ของประดับ — ถ้าไม่กรอก **ครูจะเช็คชื่อย้อนหลังไม่ได้**
เพราะระบบไม่รู้ว่าเทอมนี้มีวันไหนบ้าง

## ขั้นที่ 3 — โหลดแม่แบบไปกรอก

ไปหน้า **จัดการผู้ใช้งาน** จะเห็นปุ่ม **นำเข้านักเรียน** และ **นำเข้าครู**
ข้าง ๆ ปุ่มแต่ละอันมี **ปุ่มลูกศรชี้ลง** — กดปุ่มลูกศรเพื่อ **โหลดไฟล์แม่แบบ**

หน้า **ตารางสอน** มีปุ่มลูกศรแบบเดียวกันสำหรับแม่แบบตารางสอน
และหน้า **คลังตัวชี้วัด/ผลการเรียนรู้** มีปุ่ม **ดาวน์โหลดไฟล์แม่แบบ** เช่นกัน
(อันนี้ไม่ต้องรีบ ทำทีหลังได้ — ดู [ขั้นที่ 7](#h-ขั้นที่-7-คลังตัวชี้วัด-ผลการเรียนรู้-ทำทีหลังได้))

ไฟล์ที่โหลดมาเป็น Excel มีหัวตารางถูกต้องอยู่แล้ว พร้อมตัวอย่าง 1 บรรทัด
**ลบบรรทัดตัวอย่างทิ้งแล้วกรอกของจริงลงไป** อย่าแก้ชื่อหัวตาราง

> แม่แบบสร้างใหม่ทุกครั้งที่กดโหลด จึงตรงกับระบบเสมอ
> ไม่ต้องกังวลว่าไฟล์ที่โหลดไว้เมื่อเดือนก่อนจะเก่า — แต่โหลดใหม่ทุกครั้งจะชัวร์กว่า

### หัวตารางแต่ละไฟล์

**ไฟล์ครู**

| หัวตาราง | ต้องกรอก | หมายเหตุ |
|---|---|---|
| ชื่อผู้ใช้ | ✓ | ใช้เข้าระบบ · ห้ามซ้ำกัน · ภาษาอังกฤษหรือตัวเลข |
| ชื่อ-สกุล | ✓ | ใส่คำนำหน้าด้วย เช่น `นายอนุชา พงษ์เจริญ` |
| วิชาเอก | | สาขาที่จบมา เช่น `ฟิสิกส์` — ไม่ใช่กลุ่มสาระ |
| อีเมล | | |
| บทบาท | | ว่างไว้ = ครูผู้สอน · ใส่ `Admin` หรือ `Executive` ได้ |

**ไฟล์นักเรียน**

| หัวตาราง | ต้องกรอก | หมายเหตุ |
|---|---|---|
| รหัสนักเรียน | ✓ | ใช้เข้าระบบ · ห้ามซ้ำ · **เลข 0 นำหน้าต้องอยู่ครบ** |
| ชื่อ-สกุล | ✓ | |
| ระดับ | ✓ | เช่น `ม.1` |
| ห้อง | ✓ | ตัวเลขล้วน เช่น `2` |
| อีเมล | | |

ระบบจะต่อ **ระดับ + ห้อง** เป็น `ม.1/2` ให้เอง กรอกแยกช่องตามแม่แบบ

**ไฟล์ตารางสอน**

| หัวตาราง | ต้องกรอก | หมายเหตุ |
|---|---|---|
| รหัสวิชา | ✓ | เช่น `ว30205` |
| ชื่อวิชา | ✓ | |
| ระดับ · ห้อง | ✓ | แยกช่องเหมือนไฟล์นักเรียน |
| ชื่อผู้ใช้ครู | ✓ | ต้องตรงกับ **ชื่อผู้ใช้** ในไฟล์ครู |
| วัน | ✓ | **ชื่อวันภาษาไทยเต็ม** เช่น `จันทร์` (ย่อว่า `จ.` ก็ได้) |
| คาบ | ✓ | ตัวเลข เช่น `3` |
| สถานที่เรียน | | อาคาร/ห้องที่ไปสอนจริง เช่น `อาคาร 2 ห้อง 214` |

> **"ห้อง" กับ "สถานที่เรียน" คนละเรื่องกัน**
> "ห้อง" คือห้องเรียนของนักเรียน — เลข **1** ใน `ม.6/1` · ส่วน "สถานที่เรียน" คือที่ที่ไปนั่งเรียนจริง

**ไฟล์ตัวชี้วัด/ผลการเรียนรู้** (ไม่บังคับ ทำทีหลังได้)

| หัวตาราง | ต้องกรอก | หมายเหตุ |
|---|---|---|
| รหัสวิชา | ✓ | ต้องตรงกับ **รหัสวิชา** ในไฟล์ตารางสอน |
| ประเภท | | `พื้นฐาน` หรือ `เพิ่มเติม` เท่านั้น |
| รหัสตัวชี้วัด | ✓ | เช่น `ว 4.1 ม.4/1` · วิชาเพิ่มเติมใช้เลขลำดับ `1` `2` `3` ก็ได้ |
| คำอธิบาย | ✓ | ข้อความตัวชี้วัดหรือผลการเรียนรู้ |
| ประเมิน | | `ระหว่างทาง` หรือ `ปลายทาง` |

> **รหัสวิชา + รหัสตัวชี้วัด ห้ามซ้ำกัน**
> สองช่องนี้รวมกันคือตัวระบุของแต่ละรายการ ซ้ำในไฟล์เดียวกันระบบจะไม่รับทั้งไฟล์
> ส่วนถ้าซ้ำกับของที่มีอยู่แล้วในระบบ จะถือว่าเป็นการ**แก้ไขรายการเดิม**

### ⚠️ เลข 0 นำหน้ารหัสนักเรียน — ระวังให้มาก

Excel ชอบเปลี่ยน `01903` เป็น `1903` ให้เองโดยไม่บอก
ถ้าปล่อยผ่าน **จะกลายเป็นนักเรียนคนละคนกับของจริง** และจะไม่มีใครรู้จนครูเช็คชื่อไม่เจอ

ในแม่แบบที่โหลดไป ช่องรหัสนักเรียนถูกตั้งเป็น "ข้อความ" ไว้ให้แล้ว
แต่ถ้าก๊อปข้อมูลมาจากไฟล์อื่น เลข 0 อาจหายระหว่างทาง

**ระบบจะเตือนให้เองตอนตรวจไฟล์** — ถ้าเห็นแถวสีเหลืองเขียนว่า "อาจถูกตัด 0 นำหน้า"
ให้กลับไปดูไฟล์ก่อน **ระบบไม่เติม 0 ให้เอง** เพราะเดาแทนแล้วผิดจะแย่กว่า

## ขั้นที่ 4 — นำเข้าไฟล์ (เรียงตามนี้)

### 4.1 ครูก่อน

หน้า **จัดการผู้ใช้งาน** → ปุ่ม **นำเข้าครู** → เลือกไฟล์

### 4.2 นักเรียน

ปุ่ม **นำเข้านักเรียน** → เลือกไฟล์

### 4.3 ตารางสอนทีหลังสุด

หน้า **ตารางสอน** → ปุ่ม **นำเข้าตารางสอน** → เลือกไฟล์

**ต้องนำเข้าครูก่อนเสมอ** เพราะตารางสอนอ้างถึงชื่อผู้ใช้ครู
ถ้ายังไม่มีครูในระบบ ระบบจะปฏิเสธทั้งไฟล์และบอกว่าไม่พบใคร

### หน้าตรวจก่อนนำเข้า

เลือกไฟล์แล้วจะยังไม่บันทึกทันที — ระบบเปิดตารางให้ดูก่อน ข้างบนมีตัวเลข 3 ตัว

| | ความหมาย |
|---|---|
| **นำเข้าได้** | จำนวนแถวที่ไม่มีปัญหา |
| **เตือน** (แถวสีเหลือง) | นำเข้าได้ แต่ควรดูก่อนว่าถูกจริง |
| **ผิด** (แถวสีแดง) | ต้องแก้ในไฟล์ก่อน |

ช่อง **หมายเหตุ** ท้ายแถวบอกว่าแถวนั้นมีปัญหาอะไร และ **เลขแถวตรงกับเลขแถวใน Excel**
เปิดไฟล์ไปหาแถวนั้นได้เลย

> **มีแถวสีแดงแม้แถวเดียว = นำเข้าไม่ได้ทั้งไฟล์** ปุ่มยืนยันจะเปลี่ยนเป็น "แก้ไฟล์ก่อน"
> เป็นการตั้งใจ — นำเข้าครึ่งไฟล์แล้วมานั่งหาว่าขาดใครไปบ้าง ยากกว่าแก้ไฟล์แล้วอัปใหม่

### ⚠️ นำเข้าตารางสอนซ้ำ = ลบของเดิมทั้งเทอม

- **ครูและนักเรียน** อัปซ้ำได้เรื่อย ๆ คนที่มีอยู่แล้วจะถูกอัปเดตข้อมูลใหม่ทับ
  **ไม่มีใครถูกลบ** แม้จะหายไปจากไฟล์
  ลบครูหรือนักเรียนต้องกดลบทีละคนในหน้าจัดการผู้ใช้งาน
- **ตารางสอน** ต่างออกไป — อัปไฟล์ใหม่คือ **ลบตารางสอนของภาคเรียนนั้นทั้งหมด**
  แล้วใส่ของใหม่แทน เพราะโรงเรียนแก้ตารางทั้งใบ ไม่ได้แก้ทีละคาบ

  หน้ายืนยันจะบอกจำนวนจริงทั้งสองข้าง เช่น
  *"จะลบตารางสอนเทอม 1/2569 ที่มีอยู่ 412 แถว แล้วใส่ใหม่ 418 แถวจากไฟล์"*
  **อ่านตัวเลขนี้ก่อนกดทุกครั้ง**
- **คาบโฮมรูมและแนะแนว/วิถีพุทธไม่ถูกลบ** — ของพวกนี้ตั้งจากแท็บครูที่ปรึกษาประจำชั้น
  (ขั้นที่ 5) ไม่ได้มาจากไฟล์ อัปตารางสอนใหม่กี่ครั้งครูที่ปรึกษาก็ยังอยู่ครบ
  ถ้าไฟล์มีคาบโฮมรูมติดมาด้วย ระบบจะข้ามแถวพวกนั้นแล้วบอกจำนวนที่ข้ามไว้ในข้อความผลลัพธ์

## ขั้นที่ 5 — ครูที่ปรึกษาประจำชั้น

หน้า **จัดการผู้ใช้งาน** → แท็บ **ครูที่ปรึกษาประจำชั้น** → ปุ่ม **เพิ่มห้อง**
เลือกระดับ ห้อง แล้วเลือกครู (ใส่ได้ห้องละ 2 คน) → **บันทึก**

รายชื่อห้องในช่องให้เลือกมาจากข้อมูลนักเรียนกับตารางสอนที่นำเข้าไปแล้ว
จึงต้องทำหลังขั้นที่ 4

ขาดขั้นนี้ = **ไม่มีโฮมรูมและกิจกรรมหน้าเสาธง** และการจัดสอนแทนจะทำงานไม่ครบ

## ขั้นที่ 6 — เปลี่ยนรหัสผ่านผู้ดูแลระบบ

ถ้าการ์ดยังขึ้นข้อนี้ แปลว่าบัญชี `admin` ยังใช้รหัสเริ่มต้นอยู่ **ใครก็เดาได้**
หน้า **จัดการผู้ใช้งาน** → หาบัญชี `admin` → แก้ไข → เปลี่ยนรหัสผ่าน

## ขั้นที่ 7 — คลังตัวชี้วัด/ผลการเรียนรู้ (ทำทีหลังได้)

**ข้ามไปก่อนได้** ระบบใช้งานได้ครบโดยไม่มีขั้นนี้ แต่ทำแล้วครูทำงานเร็วขึ้นมาก

เมนู **ฝ่ายวิชาการ → คลังตัวชี้วัด/ผลการเรียนรู้** เป็นคลังกลางของทั้งโรงเรียน
เก็บตัวชี้วัดตามหลักสูตรแยกตามรหัสวิชา

เวลาครูตั้งโครงสร้างคะแนนของวิชาตัวเอง (หน้า **บันทึกคะแนน ปพ.5**) จะมีปุ่ม
**ดึงจากคลัง** — กดแล้วตัวชี้วัดของวิชานั้นเข้ามาเป็นแถวให้ทันที ไม่ต้องพิมพ์เอง
**คลังว่าง = ปุ่มนั้นขึ้นว่า "ไม่พบตัวชี้วัดของวิชา ..."** แล้วครูต้องพิมพ์เองทุกคน

**เติมได้ 2 ทาง**

1. **นำเข้าเป็นไฟล์** — กด **ดาวน์โหลดไฟล์แม่แบบ** ในหน้านั้น กรอก แล้วอัปกลับ
   ขั้นตอนเหมือนไฟล์อื่นทุกอย่าง มีหน้าตรวจให้ดูก่อนกดยืนยัน
2. **พิมพ์ทีละรายการ** ในหน้าเดียวกัน — เหมาะกับการเพิ่มทีหลังทีละข้อ

**สวิตช์ "ล้างข้อมูลตัวชี้วัดเดิมก่อนนำเข้า"**

- **เปิด** = ลบทั้งคลังแล้วใส่ใหม่จากไฟล์ · หน้ายืนยันจะบอกว่ากำลังจะลบกี่รายการ
- **ปิด** = รายการที่รหัสวิชา + รหัสตัวชี้วัดตรงกันจะถูกทับ ที่เหลืออยู่ครบ
  ใช้แบบนี้เวลาเพิ่มทีละกลุ่มสาระ

> คลังนี้**ไม่ผูกกับภาคเรียนหรือปีการศึกษา** ใส่ครั้งเดียวใช้ได้ตลอด
> ขึ้นปีใหม่ไม่ต้องนำเข้าใหม่ นอกจากหลักสูตรเปลี่ยน

นอกจากนี้ ตัวชี้วัดที่ครูพิมพ์เองในหน้าโครงสร้างคะแนน **ระบบเก็บเข้าคลังให้อัตโนมัติ**
คลังจึงค่อย ๆ เต็มขึ้นเองแม้ไม่ได้นำเข้าอะไรเลย

---

## รหัสผ่านของครูและนักเรียน

ระบบตั้งให้อัตโนมัติตอนนำเข้า:

- **ครู** รหัสผ่าน = ชื่อผู้ใช้
- **นักเรียน** รหัสผ่าน = รหัสนักเรียน

ในไฟล์นำเข้าจึงไม่มีช่องรหัสผ่าน — ตั้งใจ เพราะไฟล์พวกนี้มักถูกส่งต่อกันทางไลน์
**บอกให้ทุกคนเปลี่ยนรหัสหลังเข้าระบบครั้งแรก**

## ปัญหาที่เจอบ่อย

**"ไฟล์ขาดคอลัมน์ที่ต้องมี: ..."**
หัวตารางถูกแก้ชื่อ หรือใช้ไฟล์เก่าที่ไม่ใช่แม่แบบ → โหลดแม่แบบใหม่แล้วก๊อปข้อมูลลงไป

**"ไม่พบแถวข้อมูลใต้หัวตาราง"**
ไฟล์มีแต่หัวตาราง หรือข้อมูลไปอยู่ในชีตที่ 2 → ระบบอ่านเฉพาะ **ชีตแรก**

**ตัวหนังสือเป็นภาษาต่างดาว**
เกิดกับไฟล์ `.csv` ที่บันทึกจาก Excel — ระบบอ่านให้ได้เกือบทุกแบบแล้ว
ถ้ายังเพี้ยน ให้บันทึกไฟล์เป็น **Excel (.xlsx)** แทน แล้วอัปใหม่

**'วัน "Monday" อ่านไม่ออก'**
ช่องวันในตารางสอนต้องเป็นภาษาไทย — `จันทร์` `อังคาร` `พุธ` `พฤหัสบดี` `ศุกร์`
(ย่อ `จ.` `อ.` `พ.` `พฤ.` `ศ.` ก็ได้)

**'ไม่พบครูชื่อผู้ใช้ "..." ในระบบ — นำเข้าครูก่อน'**
นำเข้าตารางสอนก่อนครู หรือชื่อผู้ใช้ในสองไฟล์สะกดไม่ตรงกัน (เว้นวรรคเกินก็ไม่ตรง)

**'... ซ้ำกับแถว N'**
มีชื่อผู้ใช้หรือรหัสนักเรียนซ้ำกันเองในไฟล์ ระบบบอกเลขแถวคู่ที่ชนกันให้แล้ว

**'คาบ "..." รูปแบบไม่ถูกต้อง' / 'ห้อง "..." รูปแบบไม่ถูกต้อง'**
ช่องเหล่านี้ต้องเป็นตัวเลขล้วน ใส่ `3` ไม่ใช่ `คาบ 3` · ใส่ `2` ไม่ใช่ `ห้อง 2`

**ครูเข้าระบบแล้วไม่เห็นคาบสอนของตัวเอง**
ตารางสอนยังไม่ได้นำเข้า หรือนำเข้าไปคนละภาคเรียนกับที่ตั้งไว้ในขั้นที่ 2

**นำเข้าเสร็จแล้วแต่การ์ดยังไม่ติ๊ก**
กดปุ่ม **รีเฟรช** มุมขวาบนของหน้าแรก

## สื่อการสอน — ให้ครูลงสื่อเองได้

เมนู **ฝ่ายวิชาการ → สื่อการสอน** · ครูทุกคนเพิ่มการ์ดของตัวเองได้ ไม่ต้องผ่านผู้ดูแลระบบ
การ์ดมี 2 แบบ

**แบบแปะลิงก์** — ใส่ลิงก์เว็บสื่อ, Google Classroom, ไฟล์ใน Google Drive หรือคลิป YouTube
กดแล้วเปิดแท็บใหม่ · มีปุ่มแชร์เข้า Google Classroom ให้ด้วย

**แบบอัปโหลดไฟล์** — ใส่ได้**หลายไฟล์ในการ์ดเดียว** (PDF หรือรูป)
เหมาะกับหนังสือทั้งเล่ม ใบงานสแกนทีละหน้า หรือชุดเอกสารที่อยู่ด้วยกัน
คนอ่านกด **"เปิดอ่าน"** แล้วพลิกดูทีละไฟล์ในหน้าเดิม ไม่ต้องเด้งแท็บ

- เลือกไฟล์ทีเดียวหลายไฟล์ได้ ระบบทยอยอัปให้เอง
- ลำดับไฟล์ = ลำดับในสารบัญ · กดลูกศร ↑ ↓ สลับได้ทีหลัง
- ตั้งชื่อไฟล์ในสารบัญใหม่ได้ (ชื่อไฟล์จากกล้องมือถืออ่านไม่รู้เรื่อง)
- **ลบไฟล์ทีละใบแล้วกู้คืนไม่ได้** ต้องอัปใหม่ · แต่ลบทั้งการ์ดจะเข้าถังขยะ 30 วัน
- รูปจะถูกย่อให้อัตโนมัติก่อนส่ง เพื่อไม่ให้พื้นที่เต็มเร็ว

### ⚠️ "ให้นักเรียนระดับชั้นไหนเห็น" — ช่องที่พลาดแล้วเสียหาย

**ไม่เลือกชั้นเลย = เห็นเฉพาะครูและผู้ดูแลระบบ** ซึ่งเป็นค่าตั้งต้นโดยตั้งใจ
ใช้กับ **เฉลย ข้อสอบ แผนการสอน** · ระบบจะเตือนก่อนบันทึกถ้ายังไม่ได้เลือก

อยากให้นักเรียนเห็นต้องติ๊กชั้นเอง · การ์ดใบเดียวใช้สิทธิ์เดียวกันทุกไฟล์
**อยากให้บางไฟล์เห็นบางไฟล์ไม่เห็น ต้องแยกเป็นคนละการ์ด**

### ข้อจำกัดที่ควรบอกครูไว้ก่อน

| เรื่อง | ค่า |
|---|---|
| ขนาดไฟล์ | ไม่เกิน 100 MB ต่อไฟล์ |
| จำนวนไฟล์ | ไม่เกิน 50 ไฟล์ต่อการ์ด |
| ชนิดไฟล์ | PDF, JPG, PNG (ไฟล์ Word ใส่ไม่ได้ — แปลงเป็น PDF ก่อน) |
| พื้นที่รวม | โรงเรียนละ 15 GB (ผู้ติดตั้งปรับให้ได้) |

ผู้ดูแลระบบเห็นแถบบอกพื้นที่ที่ใช้ไปอยู่บนหน้าสื่อการสอน · ใกล้เต็มให้ไปลบของเก่า
ในถังขยะ เพราะ **ของในถังขยะยังกินพื้นที่อยู่** จนกว่าจะพ้น 30 วัน

## คลังเอกสารโรงเรียน — คลังกลางที่ทุกคนดูได้

เมนู **ฝ่ายบริหารงานทั่วไป → คลังเอกสารโรงเรียน** ใช้เก็บ **โครงการ · แผนงาน · รายงาน
และเอกสารประกอบ** ของโรงเรียน เลือกประเภทให้ตรงก่อนบันทึก เพื่อให้ค้นหาได้ง่าย.

- บุคลากรทุกคนเปิดดูและดาวน์โหลดไฟล์ได้
- ครูเพิ่ม แก้ไข อัปโหลด หรือลบได้เฉพาะเอกสารของตนเอง
- ผู้ดูแลระบบจัดการเอกสารของทุกคนได้
- เลือกไฟล์หลายไฟล์ได้ในครั้งเดียว ฟอร์มจะแสดงชื่อไฟล์และแถบความคืบหน้าระหว่างอัปโหลด
  กรุณารอจนเสร็จก่อนปิดหน้าต่าง เพื่อป้องกันการอัปโหลดซ้ำ

รองรับ PDF, JPG, PNG และ Word (.docx) ขนาดไม่เกิน 100 MB ต่อไฟล์. เอกสารที่ลบจะลบ
พร้อมไฟล์แนบ จึงควรตรวจชื่อรายการก่อนกดยืนยัน.

## ใช้บนมือถือและ iPad

เปิดจาก Safari หรือเพิ่มไอคอน PSSMS ไว้ที่หน้าจอหลักได้ ระบบเว้นพื้นที่แถบสถานะและ
กล้องด้านบนให้อัตโนมัติ. เมนูบน iPad จะเปิดเป็นแผงลอย; แตะพื้นที่ว่างหรือเลือกเมนูเพื่อปิด.

- แท็บจำนวนมากและตารางกว้างให้ปัดซ้าย–ขวาภายในแถบนั้น
- หน้าต่างเลือกไฟล์หรือกรอกข้อมูลเลื่อนขึ้น–ลงภายในหน้าต่างได้
- เปิด PDF จากสื่อการสอนในตัวอ่านของระบบ แล้วเลื่อนดูหน้าถัดไปได้บน iPad

## หลังตั้งค่าเสร็จ

- ให้ครู 2–3 คนลองเข้าระบบและเช็คชื่อ 1 คาบ ก่อนประกาศใช้ทั้งโรงเรียน
- ปีการศึกษาถัดไป **ไม่ต้องนำเข้านักเรียนใหม่ทั้งหมด** มีปุ่ม **เลื่อนชั้นประจำปี**
  ในหน้าจัดการผู้ใช้งาน นำเข้าเฉพาะนักเรียนเข้าใหม่
- ติดปัญหาที่ไม่มีในคู่มือนี้ ติดต่อผู้ติดตั้ง พร้อมบอก **ข้อความที่ขึ้นบนหน้าจอ**
  และ **เลขแถวที่ระบบแจ้ง** จะแก้ได้เร็วกว่ามาก
