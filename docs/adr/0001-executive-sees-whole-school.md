# Executive เห็นทั้งโรงเรียน ไม่จำกัดตามกลุ่มสาระ

`CLAUDE.md` เคยระบุว่า role `Executive` เป็น "read-only, dept-scoped" แต่ไม่มีจุดใดในระบบ
ทำ scoping จริง — `getExecutiveDashboardBundle([dept])` รับ arg มาแล้วทิ้ง ตอนออกแบบ
กระดานติดตามงานครูเราตัดสินให้**เอกสารตรงกับโค้ด**: Executive เห็นข้อมูลทั้งโรงเรียน
ต่างจาก Admin แค่ตรงที่แก้ไขอะไรไม่ได้

## เหตุผลที่ไม่ scope

- `Executive` ในระบบนี้คือ **ผอ./รอง ผอ.** (`db/demo-content.js` ตั้ง `department='บริหาร'`)
  ไม่ใช่หัวหน้ากลุ่มสาระ — ไม่มีเหตุผลทางงานที่จะซ่อนข้อมูลส่วนใดของโรงเรียนจาก ผอ.
- **`users.department` ไม่ใช่กลุ่มสาระ** มันคือ *วิชาเอก* ที่ครูจบมา (`ฟิสิกส์` `นาฏศิลป์`)
  ไม่ตรงชื่อกลุ่มสาระ 9 ใน 12 คนบน production · scope ด้วยคอลัมน์นี้ = ซ่อนข้อมูลผิดคนแบบเงียบ ๆ
- ระบบ**ไม่มี role หัวหน้ากลุ่มสาระ** และไม่มีที่เก็บว่าใครดูแลกลุ่มไหน การ scope จริงจัง
  ต้องสร้างของใหม่สองชั้นก่อน ซึ่งเป็นการแก้ปัญหาที่ยังไม่มีอยู่

## ผลที่ตามมา — สำคัญ

Admin กับ Executive เห็นผลลัพธ์**เหมือนกันทุกประการ** กระดานติดตามงานครูจึง cache ด้วย
**key เดียว** (`progress_board_{term}_{year}`) ไม่มี role ในคีย์

⚠️ ใครกลับมา scope ตาม dept ในภายหลัง **ต้องแก้ cache key พร้อมกัน** ไม่งั้นคนแรกที่เปิด
จะยัดผลลัพธ์ของตัวเองให้คนถัดไปเห็น — ข้อมูลรั่วข้ามคนโดยไม่มี error

ถ้าวันหนึ่งโรงเรียนต้องการหัวหน้ากลุ่มสาระจริง: กลุ่มสาระ derive จากอักษรแรกของ
`subject_code` ได้อยู่แล้ว (`lib/subjectGroup.js`) สิ่งที่ขาดคือที่เก็บว่า *คน* ไหนดูแล *กลุ่ม* ไหน
