# ฝั่งพฤติกรรมห้ามคำนวณ % เวลาเรียนขึ้นมาเอง

ระบบมีตัวเลข "เวลาเรียน" ที่เป็นทางการอยู่แล้ว — `functions/attendanceReport.js` คิด
`%` รายวิชาเทียบโควตา 20 สัปดาห์ แล้วส่งต่อไป ปพ.5 กับการตัดสิน **มส.**
หน้าติดตามนักเรียน (`functions/studentWatch.js`) นับ**พฤติกรรมข้ามวิชา** — ขาดโรงเรียน /
มาแล้วหนี / โดด / สาย — และ **จะไม่แสดงหรือคำนวณ `%` เวลาเรียนเด็ดขาด**

## ทำไม

- **สองตัวเลขที่หน้าตาเหมือนกันแต่ฐานต่างกัน = ตัวเลขที่เถียงกัน** ของทางการหารด้วย
  `periodsPerWeek × 20` ส่วนฝั่งพฤติกรรมมีแค่ "วันที่ครูเช็คแล้ว" ซึ่งไม่ใช่จำนวนวันเปิดเรียน
  พอครูเห็นเลขสองตัวไม่ตรงกัน ความน่าเชื่อถือเสียทั้งคู่ และคนจะเลือกเชื่อตัวที่เข้าทางตัวเอง
- **ตัวหารฝั่งพฤติกรรมสะท้อนความขยันของครู ไม่ใช่พฤติกรรมของเด็ก** — เด็กในห้องที่ครูเช็คถี่
  จะมีตัวหารใหญ่กว่าเพื่อนที่ทำตัวเหมือนกันเป๊ะ เอาไปคิดเป็น `%` แล้วชี้นิ้วผิดคน
- **คนละเจ้าของ คนละผลลัพธ์** — `มส.` เป็นกติกาของครูผู้สอน ผูกกับการตัดสินผลการเรียน
  ส่วนกลุ่มพฤติกรรมเป็นสัญญาณให้ฝ่ายปกครองเข้าไปช่วย ไม่ใช่บทลงโทษ
  ตัวเลขที่ดูเหมือนคะแนนจะทำให้คนสับสนว่ามันมีผลต่อการเรียนไหม

## ผลที่ตามมา

อันดับสะสมใช้ **เลขดิบ** (จำนวนวันที่มีอาการ) เป็นตัวเรียง และแสดงตัวหารเป็นข้อความ
(`6 / 80 วันที่เช็คแล้ว`) ให้คนอ่านตีความเอง — ไม่ยุบเป็นเปอร์เซ็นต์ ไม่จัดอันดับด้วยอัตราส่วน

⚠️ **คอลัมน์ `%` บนหน้านี้จะดู "ขาด" เสมอ และคนหลังมาจะอยากเติม** — นั่นคือเหตุผลที่ต้องมี
เอกสารฉบับนี้ ถ้าจะเติมจริง ต้องแก้ที่แหล่งเดียวคือ `attendanceReport.js` แล้วดึงมาใช้
ไม่ใช่คำนวณใหม่ที่นี่

อยากได้ตัวเลขทางการ ใช้ `getSemesterReport` / `getTeacherAtRiskDashboard` ตัวเดิม
