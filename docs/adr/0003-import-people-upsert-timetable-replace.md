# นำเข้าคน = ทับของเดิม · นำเข้าตารางสอน = ล้างทั้งเทอมแล้วใส่ใหม่

ไฟล์นำเข้าสามชนิดไม่ได้ปฏิบัติเหมือนกันตอนอัปซ้ำรอบสอง

| ไฟล์ | อัปซ้ำแล้วเกิดอะไร |
|---|---|
| ครู · นักเรียน | ทับแถวเดิมตาม `username` · **ไม่ลบใคร** ถึงจะหายไปจากไฟล์ |
| ตารางสอน | `DELETE` ตารางสอนของเทอม/ปีที่ active ทั้งหมด แล้ว `INSERT` ใหม่ |

เทอม/ปีที่ใช้เป็นขอบเขตมาจาก **ค่า active ในระบบเท่านั้น ไม่ใช่คอลัมน์ในไฟล์**

## ทำไม

- **คนหายจากไฟล์ ≠ คนออกจากโรงเรียน** ธุรการส่งไฟล์ "นักเรียนใหม่ ม.1" มาอัป ถ้าตีความ
  ว่าไฟล์คือความจริงทั้งหมด นักเรียน ม.2–ม.6 หายทั้งโรงเรียนพร้อมประวัติเช็คชื่อที่อ้างถึงเขา
  ระบบมีทางเลิกใช้บัญชีอยู่แล้ว (`status`, `promoteStudentsToNextYear`) และมันคือการตัดสินใจ
  ที่ต้องกดเอง ไม่ใช่ผลข้างเคียงของการอัปไฟล์
- **ตารางสอนเป็นก้อนเดียวทั้งเทอม** โรงเรียนไม่ได้แก้ทีละคาบ — ฝ่ายวิชาการจัดตารางใหม่ทั้งใบ
  แล้วส่งมาทับ ถ้าเป็น upsert คาบที่ถูกยกเลิกจะค้างในระบบตลอดไปโดยไม่มีใครเห็น
  ครูจะเห็นคาบผีในตารางตัวเองและระบบจะนับคาบนั้นเข้าโควตาเวลาเรียน
- **การ upsert ตารางสอนต้องมี unique key ที่ไม่มีจริง** คีย์ที่ใกล้เคียงที่สุดคือ
  (วิชา, ระดับ, ห้อง, ครู, วัน, คาบ) ซึ่งเป็นนิยามของ "แถวซ้ำ" ใน `_dupKey`
  ไม่ใช่นิยามของ "แถวเดิมที่ถูกแก้" — ย้ายคาบจากวันจันทร์ไปวันอังคารคือแถวใหม่ทั้งแถว
  จึงกันแถวซ้ำได้แต่กันคาบผีไม่ได้
- **ขอบเขต `DELETE` ห้ามมาจากช่องใน Excel** พิมพ์ปีผิดหนึ่งตัวคือลบตารางสอนของอีกปี
  ที่โรงเรียนใช้งานอยู่ทิ้ง ค่า active เปลี่ยนได้จากหน้าตั้งค่าที่เดียวและแสดงอยู่บนหน้าจอ
  ตอนกดยืนยัน คนจึงเห็นสิ่งที่จะโดนลบก่อนกด

## ผลที่ตามมา

- หน้ายืนยันก่อนนำเข้าตารางสอนต้องบอกจำนวนจริง — `จะลบตารางสอนเทอม 1/2569 ที่มีอยู่
  412 แถว แล้วใส่ใหม่ 418 แถว` ไม่ใช่ข้อความกลาง ๆ ว่า "ข้อมูลเดิมจะถูกแทนที่"
- คู่มือฝั่งโรงเรียนต้องเขียนไว้ชัดว่า **ลบนักเรียนหรือครูต้องทำในหน้าจัดการผู้ใช้**
  ลบออกจากไฟล์แล้วอัปใหม่ไม่มีผล
- `findDuplicateTimetableRows` / `removeDuplicateTimetableRows` ยังต้องอยู่ต่อ —
  แถวซ้ำยังเกิดได้จากการเพิ่มคาบทีละแถวในหน้าจัดการตารางสอน แค่ไม่เกิดจากการนำเข้าอีก
- ตารางสอนของเทอมที่ไม่ได้ active แตะไม่ได้เลยผ่านการนำเข้า ต้องสลับเทอม active ก่อน
  ยอมรับข้อจำกัดนี้แลกกับการที่ขอบเขตการลบมองเห็นได้เสมอ
